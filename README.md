# Eduard Sekan - Portfolio Website

Коротко: это статический портфолио-сайт.

## Быстрый запуск

1. Установить зависимости:
   npm install

2. Запустить локальный сервер:
   npx serve .

3. Открыть адрес из терминала (обычно http://localhost:3000).

## SCSS (по необходимости)

- Наблюдение за изменениями:
  npm run watch:css

- Одноразовая сборка:
  npm run build:css

## Важно

- В проекте нет скрипта npm run watch.
- Используйте npm run watch:css.
