# Eduard Sekan - Portfolio Website 🎨

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge)](https://eddy-hub19.github.io/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

> Modern, interactive portfolio website showcasing my projects and skills as a Front-End Developer

## ✨ Features

- 🎭 **Stunning Loader Animation** - Premium circular loader with smooth transitions
- 🌈 **Animated Gradient Background** - Dynamic color-shifting background with floating shapes
- 🎯 **3D Parallax Effects** - Interactive 3D elements that respond to mouse movement
- 💎 **Glass Morphism Design** - Modern glass-like effects throughout the site
- 📱 **Fully Responsive** - Optimized for all devices from mobile to 4K displays
- ♿ **Accessible** - WCAG compliant with reduced motion support
- ⚡ **Performance Optimized** - Fast loading with smooth 60fps animations
- 🎨 **Modern UI/UX** - Beautiful cards with depth shadows and hover effects

## 🚀 Technologies Used

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Advanced animations, Grid, Flexbox, Backdrop filters
- **JavaScript (ES6+)** - Modern vanilla JS with modules
- **AOS** - Animate On Scroll library
- **Swiper.js** - Touch slider for portfolio
- **Lottie** - Lightweight animations

### Design Features
- 3D transforms and perspectives
- CSS animations and transitions
- Glass morphism effects
- Particle systems
- Gradient animations
- Tilt and parallax effects

## 🛠️ Setup & Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Eddy-hub19/Eddy-hub19.github.io.git
   ```

2. **Navigate to directory**
   ```bash
   cd Eddy-hub19.github.io
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use a local server:
   npx serve
   ```
